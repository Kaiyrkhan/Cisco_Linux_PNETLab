# Cisco-Based Enterprise Network Design and Implementation

### Тақырыбы: Cisco құрылғылары негізінде корпоративтік желіні жобалау және конфигурациялау
### Жұмыстың орындалу қадамы: 
  1) IP Addressing;
  2) VLAN;
  3) Link Aggregation;
  4) STP;
  5) HSRP;
  6) Single area OSPFv2;
  7) Default Static Routing;
  8) DHCP;
  9) ACL;
  10) NAT.
